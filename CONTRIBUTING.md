# Colaboración

El repositorio contiene software científico complementario de una obra didáctica. Se agradecen informes de errores reproducibles, correcciones documentadas y propuestas de pruebas numéricas adicionales.

Para comunicar un problema, indique el archivo `.py`, el capítulo, la versión de Python, la orden ejecutada, los datos de entrada, la salida obtenida y el resultado esperado con justificación química y unidades.

No incluya en incidencias datos personales ni material protegido ajeno. Las contribuciones incorporadas al código del proyecto se distribuirán bajo la licencia MIT del repositorio. La aceptación de cambios está sujeta a revisión científica y técnica.
